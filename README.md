# 🚀 Proyects Curso TypeScript

Repositorio donde almaceno los proyectos, ejercicios y prácticas realizados durante mi aprendizaje de **TypeScript**.

## 📚 Objetivo

Este repositorio tiene como finalidad reforzar conceptos fundamentales y avanzados de TypeScript mediante el desarrollo de distintos proyectos prácticos.

Entre los temas trabajados se incluyen:

* Tipos básicos y tipado estático
* Interfaces
* Type Aliases
* Funciones tipadas
* Generics
* Clases y Programación Orientada a Objetos
* Módulos
* Manejo de errores
* Asincronismo con Promises y Async/Await
* Manipulación del DOM
* Integración con APIs
* Buenas prácticas de desarrollo

## ⚙️ Instalación

### Clonar el repositorio

```bash
git clone https://github.com/Fabrizio112/proyects-curso-ts.git
```

### Ingresar al proyecto

```bash
cd proyects-curso-ts
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar el proyecto

```bash
npm run dev
```

### Compilar TypeScript

```bash
npx tsc
```
